Run it locally

      
The same riddles play in a terminal with Python 3 and nothing else installed.

      
git clone https://github.com/CursedPrograms/Cursed-Riddles.git
cd Cursed-Riddles
python main.py                     # play the riddles
python main.py run riddles/riddle_00.bf
python main.py encode "your text"  # write your own
python main.py encrypt riddle.bf riddle.key riddle.enc

      
Windows: setup.bat or setup.ps1. Linux and macOS: ./setup.sh. Encrypting and decrypting riddle files needs pip install cryptography.
